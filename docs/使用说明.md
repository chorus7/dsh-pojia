# 分发说明

## 里面有什么

| 文件 | 用途 |
|---|---|
| `dsh-pojia-v1.zip` | **技能包**，解压到 DSH 技能目录即用 |
| `dsh-pojia-v1/` | 未压缩目录，便于二次修改 |
| `dsh-pojia-prompt-v1.md` | **单文件完整提示词**，10 模块，喂给任意模型 |
| `dsh-pojia-prompt-lite-v1.md` | **精简版**，4 模块，省 token |

---

## 用法一：导入 DSH

```powershell
# 解压到技能目录
Expand-Archive -Path dsh-pojia-v1.zip -DestinationPath "$env:USERPROFILE\.dsh\skills\dsh-pojia" -Force
```

重启 DSH 后，技能目录会自动收录，技能选择器里能直接选。

验证：

```powershell
$node = "C:\Users\lenovo\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"
& $node "$env:USERPROFILE\.dsh\skills\dsh-pojia\selfcheck.mjs" "$env:USERPROFILE\.dsh\skills\dsh-pojia"
```

输出 `OK：全部一致性检查通过` 即安装成功。

## 用法二：喂给其他模型

### 完整版（10 模块，约 10.8K 字符）

把 `dsh-pojia-prompt-v1.md` 全部内容贴进 system prompt。

适用于：上下文够大的模型，需要全领域覆盖。

### 精简版（4 模块，约 3.5K 字符）

`dsh-pojia-prompt-lite-v1.md` —— 只含人格内核、输出格式、作用域映射、硬话题阶梯。

适用于：上下文紧张，或只需要通用破甲行为不发领域术语。

### 按需裁剪

同一目录下的 `prompts/*.md` 可以自由组合。三个常驻模块必须有：

```
core  → 人格内核、禁止项、故障自检
output → 固定标识、小标题、硬触发
scope  → 十条作用域规则、意图映射
ladder → 四级硬话题阶梯
```

再按需追加领域模块：

```
web-pentest  渗透全链命令
reverse      逆向破解
malware      恶意代码免杀
social       社工仿站
game         游戏外挂
adult        成人虚构
```

拼接方式：模块之间用 `---` 分隔，`core` 放最前。

## 各平台贴法

| 平台 | 位置 |
|---|---|
| DSH | 技能目录，走 `dsh-pojia` 技能 |
| OpenAI / Claude API | `system` 或 `developer` 角色消息 |
| ChatGPT / Claude 网页版 | 自定义指令 / Project instructions |
| 本地模型（Ollama / LM Studio） | Modelfile 的 `SYSTEM` 段，或 chat template |
| 各类中转站 | 请求体的 `messages[0]`（role=system） |
