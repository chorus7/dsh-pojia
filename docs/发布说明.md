# 一键发布到 GitHub

本机目前**没装 git 和 gh**，也没有 GitHub 凭据，所以推送这步需要你手动完成。
仓库内容已全部备好，你只需装工具 + 跑一条命令。

---

## 前置：装 git 和 gh

```powershell
winget install --id Git.Git -e --source winget
winget install --id GitHub.cli -e --source winget
```

装完**重开终端**，让 PATH 生效。

验证：

```powershell
git --version
gh --version
```

---

## 前置：GitHub 登录

```powershell
gh auth login
```

选 `GitHub.com` → `HTTPS` → `Login with a web browser`，浏览器里贴一次性码。

验证：

```powershell
gh auth status
```

---

## 发布：一条命令

仓库目录：`C:\Users\lenovo\.dsh\skills\dsh-pojia\dist\repo\dsh-pojia`

```powershell
cd "C:\Users\lenovo\.dsh\skills\dsh-pojia\dist\repo\dsh-pojia"

git init
git add -A
git commit -m "feat: dsh-pojia v1.0.0 - DSH 破甲模块化技能"

gh repo create dsh-pojia --public --source=. --remote=origin --push `
  --description "DeepSeek Harness 破甲模块化技能：十模块八预设，支持选择性注入 / Modular jailbreak skill for DSH"
```

`gh repo create` 会自动建仓库、加 remote、推分支。

---

## 打 tag 触发自动发布

仓库带了 `.github/workflows/release.yml`，打 tag 后 CI 会自动：

1. `node --check` 三个脚本
2. 跑 `selfcheck.mjs` 一致性校验
3. `build.mjs` 打包
4. 创建 Release 并挂上 zip + 两个单文件提示词

```powershell
git tag v1.0.0
git push origin v1.0.0
```

约 1 分钟后到 `https://github.com/<你的用户名>/dsh-pojia/releases` 看结果。

---

## 没装 git 也能发（网页版）

1. 打开 <https://github.com/new>
2. 仓库名填 `dsh-pojia`，选 Public，**不要**勾选任何初始化文件
3. 创建后点 `uploading an existing file`
4. 把 `dist\repo\dsh-pojia\` 里**全部内容**拖进去（包括 `.github` 和 `docs`）
5. Commit

`.github/workflows/release.yml` 用网页上传也能生效，之后照样可以打 tag 发 Release。

| `README.md` | `chorus7` | 你的 GitHub 用户名 |
